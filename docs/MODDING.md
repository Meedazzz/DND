# GrimDice Forge 2.0 — моддинг

Модификация контента в GrimDice декларативная: приложение читает JSON и бинарные ассеты, но не выполняет JavaScript из пакетов.

## Категории медиатеки

- **Спрайты и токены** — PNG, JPG, WEBP, GIF, SVG, WebM/MP4 как хранимые ассеты. Статичные изображения можно назначить герою кнопкой «ГЕРОЮ».
- **Портреты** — изображения персонажей; назначаются листу и постановочной сцене.
- **Боевые фоны / карты** — изображение можно назначить текущей сцене кнопкой «СЦЕНА».
- **Визуальные эффекты** — изображение включается как полупрозрачный эффектный слой сцены.
- **Звуки / музыка** — локальное воспроизведение с громкостью и зацикливанием.
- **Шрифты** — WOFF, WOFF2, TTF или OTF; после включения становятся основным шрифтом интерфейса.
- **Определения анимаций** — проверяемый JSON-манифест Web Animations без скриптов.
- **Темы** — JSON с разрешёнными CSS-переменными; значения с `url()` и `expression()` отклоняются.
- **Локализация** — JSON-словарь точных строк интерфейса.

Бинарные файлы сохраняются в IndexedDB. Обычный файл кампании содержит ссылки и метаданные, а **пакет мода v2** включает бинарные файлы как data URL вместе с объектами Конструктора.

## Тема

```json
{
  "name": "Ember Night",
  "variables": {
    "--bg": "#090708",
    "--panel": "#171112",
    "--ink": "#f0dfcf",
    "--red": "#a93e2c",
    "--gold": "#d1a45e"
  }
}
```

Разрешены только имена переменных вида `--name`. Тема не может загружать внешний CSS или выполнять код.

## Анимации

```json
{
  "animations": [{
    "selector": ".actor-silhouette",
    "keyframes": [
      { "transform": "translateY(0px)" },
      { "transform": "translateY(-3px)" },
      { "transform": "translateY(0px)" }
    ],
    "options": {
      "duration": 2600,
      "iterations": "Infinity",
      "easing": "ease-in-out"
    }
  }]
}
```

Разрешённые селекторы: `.stage-actor`, `.actor-silhouette`, `.stage-backdrop`, `.stage-environment`, `.impact-hit`, `.impact-heal`. Продолжительность ограничена диапазоном 100–30000 мс; конечное число повторов — 1–20.

## Локализация

```json
{
  "locale": "en",
  "strings": {
    "Бой": "Combat",
    "Экспедиция": "Expedition",
    "Бастион": "Bastion"
  }
}
```

Словарь заменяет точные видимые строки после каждого рендера. Непереведённые строки остаются в исходной локали, поэтому частичные пакеты допустимы.

## Контент Конструктора

Категории: `abilities`, `creatures`, `items`, `effects`, `locations`, `events`, `buildings`.

У объекта обязательны как минимум `id` и `name`. Действия и предметы могут содержать `effects`:

```json
{
  "id": "ember-vial",
  "name": "Флакон живого угля",
  "type": "item",
  "rarity": "uncommon",
  "description": "Дарует регенерацию на 3 хода.",
  "effects": [
    { "op": "regen", "target": "self", "value": 2, "duration": 3 }
  ]
}
```

Поддерживаемые операции: `damage`, `heal`, `stress`, `light`, `condition`, `bleed`, `blight`, `horror`, `regen`, `move`.

## Формат пакета v2

```json
{
  "format": "grimdice-mod",
  "version": 2,
  "name": "Название пакета",
  "exportedAt": "2026-08-18T00:00:00.000Z",
  "content": {
    "abilities": [],
    "creatures": [],
    "items": [],
    "effects": [],
    "locations": [],
    "events": [],
    "buildings": []
  },
  "assets": [{
    "id": "uuid",
    "kind": "sprites",
    "name": "hero.png",
    "size": 12345,
    "type": "image/png",
    "data": "data:image/png;base64,..."
  }]
}
```

Импорт v1 без бинарных файлов остаётся совместимым. Повторный импорт не дублирует объект или ассет с тем же `id`.

## Авторские права

Включайте только ассеты и тексты, которыми вправе распоряжаться. GrimDice не содержит и не требует материалы других коммерческих игр; визуальная постановка проекта оригинальна.
