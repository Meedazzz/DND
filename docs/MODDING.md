# Моддинг «Драконьей Саги» 2.2

Модификации декларативны: приложение читает JSON и встроенные бинарные материалы, но **не исполняет JavaScript** из пакета.

## Пакет

Минимальная структура:

```json
{
  "format": "dragon-saga-mod",
  "version": 1,
  "manifest": {
    "name": "Северная палитра",
    "author": "Автор",
    "createdAt": "2026-08-21T00:00:00.000Z",
    "appVersion": "2.2.0"
  },
  "content": {
    "items": [],
    "actions": [],
    "creatures": [],
    "mods": []
  },
  "assets": [],
  "theme": {
    "accent": "#8f3d38",
    "gold": "#b49a6d"
  },
  "animations": {
    "idleDuration": 3.2
  },
  "localization": {
    "Обзор": "Overview",
    "Поле боя": "Battlefield"
  }
}
```

Пакет импортируется и экспортируется в разделе **«Конструктор»**. При импорте внутренним записям назначаются новые ID, поэтому пакет не может перезаписать существующий объект по совпадению идентификатора.

## Материалы

Элемент `assets` соответствует записи медиатеки:

```json
{
  "id": "asset-source-id",
  "name": "hero.png",
  "kind": "image",
  "mime": "image/png",
  "size": 12345,
  "data": "data:image/png;base64,..."
}
```

Поддерживаемые категории:

- `image` — портрет, полноразмерная PNG/WebP/JPEG-модель, фон или объект сцены;
- `audio` — звук или музыка;
- `model` — GLB или самодостаточный GLTF со встроенными данными; такие модели можно размещать в конструкторе сцен;
- `spell` — материал заклинания;
- `mod` — декларативное определение или вспомогательный пакет.

Полноразмерные 2D-модели назначаются персонажу в редакторе листа. Прозрачный PNG обычно даёт лучший результат на поле боя.

## Тема

Импортируемая тема использует только проверяемые HEX-цвета:

- `accent` — активные линии, кнопки и предупреждения;
- `gold` — декоративные северные акценты.

`animations.idleDuration` задаёт длительность спокойного движения модели от 1 до 10 секунд. Произвольный CSS и скрипты не поддерживаются намеренно.

## Локализация

`localization` — словарь точных видимых строк. После рендера приложение заменяет совпадающие текстовые узлы. Это подходит для названий навигации, кнопок и кратких подписей. Пользовательские названия мира, городов и персонажей хранятся в самой кампании и не требуют словаря.

## Контент

`content.items`, `content.actions`, `content.creatures` и `content.mods` — записи Конструктора. Импорт не выставляет существо на поле, не выдаёт предмет герою и не создаёт сцену автоматически: мастер сам решает, где использовать материал.

## Безопасность и права

- Импортировать пакет и менять Конструктор может только мастер.
- Медиатеку меняет мастер или участник с явным разрешением.
- Пакет не должен содержать чужие коммерческие материалы без права распространения.
- HTML, JavaScript и удалённые сетевые зависимости не выполняются.
