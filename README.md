# «Драконья Сага» — Python Battle Desk 5.0.0 «Гримуар»

Самостоятельный боевой стол D&D 5e на **Python 3.11+ и PySide6**: театральная готическая сцена, крупные портреты, кровь и старое золото, строгая типографика, компактные мастерские инструменты и действия в один клик.

Релиз 5.0 «Гримуар» выводит стол на новый уровень: **оригинальные арт-заглушки** на всех участников и сцену, **встроенный бестиарий**, **спасброски от смерти**, **каталог состояний**, **конструктор встреч по XP** и **Хроника боя** с экспортом.

## Что нового в 5.0

- 🎨 **Оригинальные арт-заглушки**: девять уникальных портретов (пять архетипов героев, общий герой, моб / элита / босс), фон боевой сцены и гербовый баннер — всё нарисовано для саги и упаковано в приложение. Свой PNG/JPG/WebP по-прежнему важнее любой заглушки.
- 📕 **Бестиарий**: десять готовых существ трёх рангов — от гоблина и мертвяка до Архимага Багрового Хора и Древнего змея Золы. Предпросмотр листа, вывод группы до шести особей с римской нумерацией, автоматическая расстановка по рядам.
- 💀 **Спасброски от смерти** по правилам 5e: d20 ≥ 10, нат. 1 — два провала, нат. 20 — подъём с 1 ОЗ; три успеха стабилизируют, три провала убивают. Отметки видны на карточке, работают и по сети через авторитетный сервер.
- 🩸 **Каталог состояний**: 15 базовых состояний 2014/2024 с краткими описаниями, поиском по русскому и английскому имени, плюс свои отметки через запятую.
- ⚔ **Конструктор встреч**: XP-бюджет по CR, множители численности, пороги сложности партии и оценка «пустяковая…смертельная»; в один клик подхватывает выставленных на сцене участников.
- 📜 **Хроника боя**: полный журнал стола с фильтром и экспортом в Markdown — летопись кампании ведётся сама.
- 🏷 **Ранги участников** (`hero / mob / elite / boss`) задаются при импорте и из бестиария: от них зависят маркеры карточек и портретные заглушки.

## Что готово

- четыре ряда `Т1 → А1 → А2 → Т2`, максимум два участника в ряду и резерв;
- пять нейтральных листов-заполнителей, четыре сразу выставлены на сцене с портретами архетипов;
- отдельный вид мастера и сфокусированный лист одного назначенного игроку героя;
- основной рабочий путь — вставка полного непрерывного русского или английского статблока с предпросмотром до добавления моба, элиты или босса;
- исходник сохраняется дословно, а распознанные и оставленные по умолчанию поля разделены в аудите без выдумывания отсутствующих данных;
- распознавание имени/типа, КД, ОЗ, скорости, характеристик, спасбросков, spell DC/атаки, защит, особенностей без отдельного заголовка, действий/реакций/легендарных действий, урона, лечения, recharge и ресурсов `2/2` или `3/Day`;
- автоматические попадания, критический урон, спасброски (включая половину урона), лечение и расход ресурсов;
- ручной редактор действий и ресурсов поверх сохранённого исходника, короткий/долгий отдых и Кости Хитов;
- инициатива, цель, ОЗ, временные ОЗ, состояния из каталога и журнал результатов;
- домашние правила: провоцированные атаки, Фланг, Натиск, Тактическая передышка, Укрытие тыла, подготовка босса и спасброски от смерти;
- переключение D&D 5e 2014/2024;
- PNG/JPG/WebP на сцене без обрезки; GLB/GLTF сохраняются как вложения персонажа и показываются нейтральным 3D-заполнителем;
- компактный диалог «Материалы» копирует полноразмерные изображения, модели, музыку, PDF и текст в локальное хранилище;
- атомарные JSON-сохранения;
- встроенный Python-сервер для LAN/Hamachi и архитектура для HTTPS-развёртывания;
- фильтрация сетевого состояния: игрок получает полный лист только своего героя и безопасные проекции выставленных участников;
- сетевые атаки, перемещения, Фланг, Натиск, Отход, передышка, отдых, спасброски от смерти и анализ подготовки разрешаются сервером по полному авторитетному состоянию;
- обычная синхронизация игрока не может подделать позицию, экономику действий, журнал или урон другой цели; контрмера босса скрыта до успешного анализа;
- ревизии защищают комнату от устаревшей записи, а PyInstaller и GitHub Actions собирают Windows, Linux и macOS (арт-ресурсы упаковываются в сборку через `--add-data`).

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Тесты:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

## Быстрый бой

1. Откройте **«Бестиарий»** и выведите группу мобов или босса одним кликом — либо нажмите **«+ Импорт моба / босса»** и вставьте описание целиком без подготовки.
2. Проверьте распознанный лист и аудит справа, затем добавьте участника; он попадёт в свободное место А2/Т2 либо в резерв.
3. Нажмите **«Бросить инициативу»**.
4. Щёлкните по вражеской фигуре, затем по нужному действию в нижней консоли или по **«Ход»** на карточке.
5. Перемещения, спасброски от смерти и домашние приёмы находятся в меню `•••` карточки.

## Сеть

В приложении откройте **«Общий стол»**:

1. мастер нажимает **«Запустить сервер здесь»**;
2. подключается к `http://127.0.0.1:4173` как мастер и создаёт комнату;
3. участники в LAN/Hamachi используют `http://IP-МАСТЕРА:4173` и тот же код;
4. игрок подключается к комнате, после чего мастер выбирает игрока и героя в диалоге **«Общий стол»** и нажимает **«Назначить героя»**.

Отдельный сервер:

```bash
python -m dragon_saga.server --host 0.0.0.0 --port 4173
```

Для публичной игры поставьте сервер за HTTPS reverse proxy. Максимальное JSON-состояние комнаты — 256 МБ.

## Структура проекта

| Модуль | Назначение |
| --- | --- |
| `dragon_saga/models.py` | Датаклассы кампании, участники, действия, ресурсы, стартовая сцена |
| `dragon_saga/rules.py` | Движок: кубы, инициатива, перемещения, урон, отдых, спасброски от смерти, подготовка босса |
| `dragon_saga/parser.py` | Разбор непрерывных статблоков RU/EN с аудитом |
| `dragon_saga/bestiary.py` | Встроенный бестиарий (10 существ, 3 ранга) |
| `dragon_saga/conditions.py` | Каталог состояний 5e с поиском и описаниями |
| `dragon_saga/encounter.py` | Конструктор встреч: XP, множители, пороги сложности |
| `dragon_saga/assets.py` | Реестр встроенных арт-заглушек и подбор портрета |
| `dragon_saga/resources/` | Оригинальные портреты, фон сцены и гербовый баннер |
| `dragon_saga/ui.py` | Интерфейс стола, диалоги, страницы и Хроника |
| `dragon_saga/server.py` / `network.py` | Авторитетный сетевой стол и клиент |
| `dragon_saga/storage.py` | Атомарные JSON-сохранения |
