# Драконья Сага Desktop 2.2.0

**«Драконья Сага»** — самостоятельный настольный стол кампании D&D 5e для мастера и игроков. Приложение работает в браузере и как настольная программа для Windows, Linux и macOS. Новая кампания открывается пустой: героев, противников, атак, предметов, сцен, магазинов и столкновений пользователь создаёт сам.

Проект использует оригинальный интерфейс в северном тёмном фэнтези. Darkest Dungeon и TaleSpire являются только общими визуальными и функциональными ориентирами; их код, интерфейс и материалы не копируются.

## Основные возможности

- отдельные рабочие пространства мастера и игрока;
- точный импорт русских и английских текстовых статблоков с сохранением исходника;
- листы персонажей, действия, ограниченные ресурсы, снаряжение, валюта и инвентарь;
- автоматические `d20`, попадание, критический урон, спасбросок, лечение и расход ресурса;
- правила кампании 5e 2014 или 2024;
- общий журнал, личные записи и публикуемая хроника;
- северный атлас, редактируемые места и маршруты;
- города, торговцы, остатки, покупка и продажа;
- сцены с фоном и относительно размещаемыми/масштабируемыми PNG, GLB и самодостаточными GLTF-объектами;
- медиатека изображений, полноразмерных моделей, звука, музыки и декларативных пакетов;
- встроенный редактор изображений с кадрированием, размером, цветокоррекцией, эффектами, chroma key, подписью и экспортом;
- GM-права на контент и медиатеку с явной выдачей разрешения другим участникам;
- локальная игра, LAN/Hamachi и серверная архитектура для публичного HTTPS-развёртывания;
- нативные JSON-сохранения и обновление настольных сборок через GitHub Releases.

## Тактическая линия 40 футов

Поле разделено на четыре зоны по 10 футов:

`Т1 (тыл героев) → А1 (авангард героев) → А2 (авангард врагов) → Т2 (тыл врагов)`

Реализованы:

1. движение между соседними зонами за 10 футов с видимым остатком скорости;
2. ближняя досягаемость между участниками в одной или соседней зоне;
3. провоцированные атаки при выходе из авангарда без Отхода;
4. фланг из своего тыла во вражеский тыл при скорости 40+ за всё движение;
5. Натиск из тыла в авангард с преимуществом первой ближней атаки и ответной уязвимостью;
6. Тактическая передышка в безопасном дружественном тылу за бонусное действие и Кость Хитов;
7. укрытие тыла: `+2 КД` и помеха прямым дальнобойным атакам при занятом союзником авангарде;
8. две и более перекрывающиеся полноразмерные модели в зоне, idle-анимация, индивидуальный масштаб, состояния и текущий ход;
9. общий баннер попадания/промаха и журнал бросков;
10. подготовка действия босса, Восприятие/Анализ и дистанционная Сл контрмеры.

## Запуск из исходников

Требуется Node.js `>=22.12.0`.

```bash
npm ci
npm test
npm start
```

Откройте `http://localhost:4173`.

Настольный режим:

```bash
npm run desktop
```

## Сеть

Мастер создаёт код комнаты в разделе **«Общий стол»**. На LAN/Hamachi участники открывают адрес компьютера мастера и вводят тот же код. Для публичной игры сервер следует разместить за HTTPS reverse proxy.

Сервер:

- выдаёт единственную роль владельца комнаты;
- не отдаёт игрокам GM-заметки, закрытые места, скрытых врагов и приватные листы;
- принимает полный лист только назначенного игроку героя и позволяет мастеру принудительно переназначить владельца;
- ограничивает боевые изменения активным ходом;
- оставляет мир, сцены, права и контент под властью мастера;
- проверяет ревизии и отклоняет устаревшие записи;
- разрешает изменения медиатеки только мастеру и назначенным редакторам.

## Сохранения и ассеты

Сохранение имеет формат JSON со схемой `dragon-saga-campaign`. В него включаются материалы медиатеки как data URL, поэтому крупные кампании создают крупные файлы. Встроенный импорт ограничивает один файл восемью мегабайтами, а сервер комнаты принимает тело до 64 МБ.

Текст статблока хранится в `sourceText` полностью. Импортёр извлекает только явно найденные поля и формирует аудит; неуказанные значения остаются безопасными начальными значениями и отмечаются предупреждениями.

## Моды

Мод-пакеты `dragon-saga-mod` декларативны и не исполняют JavaScript. Они могут содержать материалы, записи конструктора, цветовую тему, параметры idle-анимации и словарь локализации. Схема и пример: [docs/MODDING.md](docs/MODDING.md).

## Сборки и выпуск

```bash
npm run pack:windows
npm run pack:linux
npm run pack:mac
```

GitHub Actions собирает:

- Windows x64 NSIS;
- Linux x64 AppImage и DEB;
- macOS universal DMG и ZIP для автообновления.

Сборки версии 2.2.0 намеренно не подписываются. Порядок выпуска описан в [docs/RELEASE.md](docs/RELEASE.md).
