# «Драконья Сага» — Python Battle Desk 3.2.0

Новая самостоятельная версия боевого стола D&D 5e, написанная на **Python 3.11+ и PySide6**. Старый интерфейс управления кампанией не переносился: в приложении остались только **боевая сцена**, **персонажи**, быстрый текстовый импорт, кубы и сетевой стол.

Сцена рисуется процедурно средствами Qt. В проект не включены прежние референсные фотографии или заимствованные игровые материалы. Визуальное направление — спокойное северное dark fantasy с собственными цветами, силуэтами и компоновкой.

## Что готово

- четыре ряда `Т1 → А1 → А2 → Т2`, максимум два участника в ряду и резерв;
- пять нейтральных листов-заполнителей, четыре сразу выставлены на сцене;
- отдельный вид мастера и сфокусированный лист одного назначенного игроку героя;
- точный русский/английский импорт: исходник сохраняется без переписывания, а отсутствующие поля отмечаются аудитом;
- распознавание КД, ОЗ, скорости, характеристик, атак, спасбросков и ресурсов `2/2`;
- автоматические попадания, критический урон, спасброски (включая половину урона), лечение и расход ресурсов;
- ручной редактор действий и ресурсов поверх сохранённого исходника, короткий/долгий отдых и Кости Хитов;
- инициатива, цель, ОЗ, временные ОЗ, состояния и журнал результатов;
- домашние правила: провоцированные атаки, Фланг, Натиск, Тактическая передышка, Укрытие тыла и подготовка босса;
- переключение D&D 5e 2014/2024;
- PNG/JPG/WebP на сцене без обрезки; GLB/GLTF сохраняются как вложения персонажа и показываются нейтральным 3D-заполнителем;
- компактный диалог «Материалы» копирует полноразмерные изображения, модели, музыку, PDF и текст в локальное хранилище;
- атомарные JSON-сохранения;
- встроенный Python-сервер для LAN/Hamachi и архитектура для HTTPS-развёртывания;
- фильтрация сетевого состояния: игрок получает полный лист только своего героя и безопасные проекции выставленных участников;
- сетевые атаки, перемещения, Фланг, Натиск, Отход, передышка, отдых и анализ подготовки разрешаются сервером по полному авторитетному состоянию;
- обычная синхронизация игрока не может подделать позицию, экономику действий, журнал или урон другой цели; контрмера босса скрыта до успешного анализа;
- ревизии защищают комнату от устаревшей записи, а PyInstaller и GitHub Actions собирают Windows, Linux и macOS.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Тесты:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

## Быстрый бой

1. Нажмите **«＋ Быстро врага»** и вставьте статблок без подготовки.
2. Враг автоматически попадёт в свободное место А2/Т2 либо в резерв.
3. Нажмите **«Бросить инициативу»**.
4. Щёлкните по вражеской фигуре, затем **«Действие»** у активного участника.
5. Остальные перемещения и домашние приёмы находятся в меню `⋯` карточки.

## Сеть

В приложении откройте **«Общий стол»**:

1. мастер нажимает **«Запустить сервер здесь»**;
2. подключается к `http://127.0.0.1:4173` как мастер и создаёт комнату;
3. участники в LAN/Hamachi используют `http://IP-МАСТЕРА:4173` и тот же код;
4. игрок подключается к комнате, после чего мастер выбирает игрока и героя в диалоге **«Общий стол»** и нажимает **«Назначить героя»**.

Отдельный сервер:

```bash
python -m dragon_saga.server --host 0.0.0.0 --port 4173
```

Для публичной игры поставьте сервер за HTTPS reverse proxy. Максимальное JSON-состояние комнаты — 256 МБ.
