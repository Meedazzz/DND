# «Драконья Сага» Desktop 2.2.0

**«Драконья Сага»** — боевой стол D&D 5e для мастера и игроков. Приложение работает в браузере и как полноценная настольная программа для Windows, Linux и macOS.

Версия 2.2.0 открывается сразу на общей боевой сцене. В стартовой кампании есть один оригинальный нейтральный северный фон, четыре поставленных силуэта героев и пятый лист героя в резерве. Это заполнители, а не навязанные персонажи: их можно заменить собственными листами, PNG или 3D-моделями.

Интерфейс выполнен в оригинальном северном dark-fantasy направлении. Darkest Dungeon, TaleSpire и LongStoryShort служат только общими визуальными и функциональными ориентирами; их код, интерфейс и материалы не копируются.

## Видимая структура

У мастера доступны только три основных раздела:

- **Боевая сцена** — поле, инициатива, компактные карточки участников, быстрые правки ОЗ/состояний, импорт врага и постоянная панель кубов;
- **Герои** — пять стартовых листов-заполнителей и импорт собственных листов;
- **Враги** — импортированные противники и их полные статблоки.

Игрок видит общую боевую сцену и один назначенный ему лист. Поставленные союзники и противники остаются видны на сцене, но чужие листы, действия, исходники импорта и приватные данные ему не выдаются.

Журнал, карта, города, отдельная медиатека, фоторедактор и конструктор не показаны в навигации этой версии. Необходимые низкоуровневые возможности сохранены в формате кампании и коде, но не загромождают боевой стол.

## Основные возможности

- точный импорт русских и английских текстовых статблоков с дословным сохранением исходника;
- распознавание действий, формул урона, спасбросков и ресурсов вида `2/2`;
- правила D&D 5e 2014 и 2024;
- автоматические броски `d20`, попадание, критический урон, спасбросок, лечение и расход ресурса;
- один-клик импорт врага с автоматическим размещением в А2 или Т2;
- постоянные кубы и последние результаты справа от сцены;
- полноразмерные PNG, GLB и самодостаточные GLTF с индивидуальным масштабом;
- загрузка изображений, моделей, звука, музыки и декларативных пакетов через диалог сцены;
- локальная игра, LAN/Hamachi и серверная архитектура для публичного HTTPS-развёртывания;
- нативные JSON-сохранения и обновление настольных сборок через GitHub Releases.

## Тактическая линия 40 футов

Поле разделено на четыре зоны по 10 футов:

`Т1 (тыл героев) → А1 (авангард героев) → А2 (авангард врагов) → Т2 (тыл врагов)`

Реализованы:

1. движение между соседними зонами за 10 футов с видимым остатком скорости;
2. ближняя досягаемость между участниками в одной или соседней зоне;
3. провоцированные атаки при выходе из авангарда без Отхода;
4. фланг из своего тыла во вражеский тыл при скорости 40+ за всё движение;
5. Натиск из тыла в авангард с преимуществом первой ближней атаки и ответной уязвимостью;
6. Тактическая передышка в безопасном дружественном тылу за бонусное действие и Кость Хитов;
7. укрытие тыла: `+2 КД` и помеха прямым дальнобойным атакам при занятом союзником авангарде;
8. до двух визуально разделённых полноразмерных участников в каждом ряду, idle-анимация, состояния и индивидуальный масштаб;
9. выбор цели, автоматическое попадание/урон, общий баннер попадания или промаха и журнал;
10. подготовка действия босса, проверки Восприятия/Анализа и дистанционная Сл контрмеры.

## Запуск из исходников

Требуется Node.js `>=22.12.0`.

```bash
npm ci
npm test
npm start
```

Откройте `http://localhost:4173`.

Настольный режим:

```bash
npm run desktop
```

## Сеть

Мастер открывает **«Общий стол»**, создаёт код комнаты и назначает каждому игроку одного героя. На LAN/Hamachi участники используют адрес компьютера мастера и тот же код. Для публичной игры сервер следует разместить за HTTPS reverse proxy.

Сервер:

- выдаёт единственную роль владельца комнаты;
- сохраняет на сцене проекции всех поставленных участников;
- отдаёт игроку полный лист только назначенного героя;
- не раскрывает чужие действия, инвентарь, исходники импорта и GM-данные;
- ограничивает боевые изменения активным ходом;
- позволяет мастеру принудительно переназначать владельца героя;
- проверяет ревизии и отклоняет устаревшие записи.

## Сохранения и ассеты

Сохранение имеет JSON-схему `dragon-saga-campaign`. Материалы хранятся как data URL, поэтому крупные кампании создают крупные файлы. Один импортируемый файл ограничен 48 МБ, тело сетевого состояния — 256 МБ. Полноразмерные изображения не уменьшаются и не обрезаются.

Текст статблока хранится в `sourceText` полностью, включая исходные переводы строк и пробелы. Импортёр извлекает только явно найденные поля и формирует аудит; безопасные значения схемы для отсутствующих полей отмечаются предупреждениями.


- Linux x64 AppImage и DEB;
- macOS universal DMG и ZIP для автообновления;
- `SHA256SUMS.txt` и GitHub Release.

Сборки 2.2.0 намеренно не подписываются. Порядок публикации единого архива исходников описан в [docs/RELEASE.md](docs/RELEASE.md).
